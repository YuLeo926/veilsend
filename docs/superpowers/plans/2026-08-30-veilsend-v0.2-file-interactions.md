# VeilSend v0.2 File Interaction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users drop one image or PDF into the existing safe session boundary and review PDFs with session-only zoom and keyboard navigation without changing redaction geometry.

**Architecture:** Tauri's native webview drag event supplies a transient path; a small TypeScript classifier enforces the one-file UX, while new Rust commands reuse the same session loading, type/size/content, detector, and freshness checks as the picker. PDF zoom scales the image and its overlay as one wrapper, keeping all automatic and manual rectangles in existing page-relative coordinates.

**Tech Stack:** Tauri 2 native drag-drop events, Rust 2024 session stores, React 19 hooks, TypeScript 5.9, Vitest 4, CSS.

**Spec:** `docs/superpowers/specs/2026-08-30-veilsend-v0.2-trusted-release-design.md`

## Global Constraints

- Drag-drop is desktop-only, accepts exactly one image (`.jpg`, `.jpeg`, `.png`) or one `.pdf` in its matching add screen, and never accepts directories or multiple paths.
- Hover events may change visual state but must not read file bytes or call a Rust open command.
- Rust revalidates local-file status, extension, content/header, byte/page/pixel limits, and detector completion; frontend classification is not a security boundary.
- A load failure leaves no half-loaded active session and does not display the rejected path.
- Drop is disabled while busy and outside the matching workflow's add stage; picker and keyboard controls remain available.
- No dropped path is persisted to local storage, history, diagnostics, logs, or a recent-file list.
- PDF zoom is session-only, ranges from 50% to 200% in 25% steps, and includes Fit width/Fit page.
- Zoom must not modify `ImageRect`, `NormalizedRect`, `PdfManualRegion`, backend coordinates, or saved output.
- `PageUp`/`PageDown`, `+`/`-`, and `Escape` do nothing while focus is in an editable control; Escape removes only an uncommitted draft.

```rust
fn validate_local_file(path: &Path, extensions: &[&str]) -> Result<(), String> {
    if !path.is_file() {
        return Err("Drop one supported local file, not a folder.".to_owned());
    }
    let supported = path.extension().and_then(|value| value.to_str())
        .is_some_and(|value| extensions.iter().any(|expected| value.eq_ignore_ascii_case(expected)));
    if !supported {
        return Err("That file type is not supported in this workspace.".to_owned());
    }
    Ok(())
}

fn load_image_path(path: PathBuf, state: &ImageSessionStore) -> Result<ImageSession, String> {
    validate_local_file(&path, &["jpg", "jpeg", "png"])?;
    let summary = state.replace_file(&path)?;
    let loaded = state.resolve(&summary.id)
        .and_then(|resolved| build_image_session(summary, &resolved.bytes));
    match loaded {
        Ok((session, reviewed)) => {
            state.set_reviewed(&session.session_id, reviewed)?;
            Ok(session)
        }
        Err(error) => {
            let _ = state.clear();
            Err(error)
        }
    }
}
```

```ts
export type DropKind = "image" | "pdf";
const allowed = { image: [".jpg", ".jpeg", ".png"], pdf: [".pdf"] } as const;

export function classifyFileDrop(paths: string[], kind: DropKind, busy: boolean) {
  if (busy) return { ok: false as const, message: "Wait for the current operation to finish." };
  if (paths.length !== 1) return { ok: false as const, message: "Drop exactly one supported file." };
  const path = paths[0];
  if (!allowed[kind].some((extension) => path.toLowerCase().endsWith(extension))) {
    return { ok: false as const, message: kind === "image" ? "Drop one JPEG or PNG image." : "Drop one PDF document." };
  }
  return { ok: true as const, path };
}

export function dropPrompt(kind: DropKind, busy: boolean) {
  if (busy) return kind === "image" ? "Wait for the current image operation" : "Wait for the current PDF operation";
  return kind === "image" ? "Choose, paste, or drop one JPEG/PNG" : "Choose or drop one PDF";
}
```

```ts
// core of useDesktopFileDrop.ts
useEffect(() => {
  if (!enabled || !isDesktop()) return;
  let disposed = false;
  let unlisten: (() => void) | undefined;
  void getCurrentWebview().onDragDropEvent((event) => {
    if (event.payload.type === "enter" || event.payload.type === "over") { onActive(true); return; }
    if (event.payload.type === "leave") { onActive(false); return; }
    onActive(false);
    const decision = classifyFileDrop(event.payload.paths, kind, busy);
    if (decision.ok) void onDrop(decision.path);
    else onError(decision.message);
  }).then((stop) => { if (disposed) stop(); else unlisten = stop; });
  return () => { disposed = true; unlisten?.(); onActive(false); };
}, [busy, enabled, kind, onActive, onDrop, onError]);
```

Use memoized callbacks at call sites so the listener is not repeatedly recreated. The hook must not call `onDrop` for `over` or `leave`; do not store the path beyond the asynchronous loader call.

```ts
export type PdfZoom = "fitWidth" | "fitPage" | 50 | 75 | 100 | 125 | 150 | 175 | 200;
const zooms = [50, 75, 100, 125, 150, 175, 200] as const;

export function stepPdfZoom(current: PdfZoom, direction: -1 | 1): PdfZoom {
  const value = typeof current === "number" ? current : 100;
  const index = zooms.indexOf(value);
  return zooms[Math.min(zooms.length - 1, Math.max(0, index + direction))];
}

export function clampPdfPage(current: number, pageCount: number, delta: -1 | 1) {
  return Math.min(Math.max(pageCount - 1, 0), Math.max(0, current + delta));
}

export function isEditableTarget(target: EventTarget | null) {
  const candidate = target as { tagName?: unknown; isContentEditable?: unknown } | null;
  return Boolean(candidate && (candidate.isContentEditable === true
    || (typeof candidate.tagName === "string" && /^(INPUT|TEXTAREA|SELECT)$/.test(candidate.tagName))));
}

export function imageRectPercentStyle(rect: ImageRect, pageWidth: number, pageHeight: number) {
  return {
    left: `${(rect.x / pageWidth) * 100}%`, top: `${(rect.y / pageHeight) * 100}%`,
    width: `${(rect.width / pageWidth) * 100}%`, height: `${(rect.height / pageHeight) * 100}%`,
  };
}
```

Reject zero page dimensions in `imageRectPercentStyle` with a fixed developer error; production page summaries already require positive dimensions.

Implement the shortcut mapper as a pure function before wiring React:

```ts
export function pdfShortcutAction(
  event: { key: string; target: EventTarget | null },
  stage: "add" | "review" | "result",
  busy: boolean,
) {
  if (stage !== "review" || busy || isEditableTarget(event.target)) return null;
  if (event.key === "PageDown") return "nextPage" as const;
  if (event.key === "PageUp") return "previousPage" as const;
  if (event.key === "+" || event.key === "=") return "zoomIn" as const;
  if (event.key === "-") return "zoomOut" as const;
  if (event.key === "Escape") return "cancelDraft" as const;
  return null;
}
```

Add labelled toolbar buttons for Fit width, Fit page, minus, current percentage/mode, and plus. The page wrapper receives one of `zoom-fit-width`, `zoom-fit-page`, or an inline pixel width derived from `preview.width * zoom / 100`; the image and `.pdf-draw-layer` remain children of that same wrapper.

Replace inline automatic-overlay calculations with `imageRectPercentStyle`; manual rectangles remain percentages from `NormalizedRect`.

```ts
useEffect(() => {
  if (stage !== "review" || busy) return;
  const onKeyDown = (event: KeyboardEvent) => {
    const action = pdfShortcutAction(event, stage, busy);
    if (!action) return;
    event.preventDefault();
    if (action === "nextPage") setSelectedPage((page) => clampPdfPage(page, session?.pageCount ?? 0, 1));
    if (action === "previousPage") setSelectedPage((page) => clampPdfPage(page, session?.pageCount ?? 0, -1));
    if (action === "zoomIn") setZoom((value) => stepPdfZoom(value, 1));
    if (action === "zoomOut") setZoom((value) => stepPdfZoom(value, -1));
    if (action === "cancelDraft") setDraft(null);
  };
  window.addEventListener("keydown", onKeyDown);
  return () => window.removeEventListener("keydown", onKeyDown);
}, [busy, session?.pageCount, stage]);
```

## Plan Self-Review

- Design sections 11–12 are covered: single-file native drops, Rust revalidation, busy/replacement behavior, zoom limits/modes, shortcuts, focus protection, and accessibility.
- The only new path-bearing value is the transient Tauri command argument; it is not returned by error messages or diagnostics and is retained only by the existing active Rust session.
- Hover never invokes a loader; frontend extension checks never replace backend extension/content/limit checks.
- Automatic and manual overlays share the scaled page wrapper, while their data models and export request remain unchanged.
- There is no page reorder, multi-document state, persisted zoom, HTML FileReader, or browser-mode filesystem access.
