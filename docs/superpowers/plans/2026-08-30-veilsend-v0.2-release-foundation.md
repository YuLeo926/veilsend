# VeilSend v0.2 Release Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a version-locked, continuously tested Windows x64 beta that GitHub Actions packages into a traceable draft Release.

**Architecture:** Keep release policy in small repository scripts that can be tested without GitHub. CI runs the existing frontend and Rust gates with read-only permissions; the tag workflow re-runs them, builds Tauri once, stages deterministic asset names, creates a CycloneDX SBOM and attestations, and uploads only to a draft pre-release.

**Tech Stack:** Node.js 24, React/Vitest, Rust 2024, Cargo, Tauri 2, PowerShell 7, GitHub Actions, NSIS, Syft/CycloneDX.

**Spec:** `docs/superpowers/specs/2026-08-30-veilsend-v0.2-trusted-release-design.md`

## Global Constraints

- Target identity is exactly app version `0.2.0-beta.1`, Git tag `v0.2.0-beta.1`, product `VeilSend`, platform `Windows 10/11 x64`, channel `beta`.
- `package.json`, `src-tauri/Cargo.toml`, and `src-tauri/tauri.conf.json` must carry the same version.
- GitHub Releases is the only official binary channel; canonical assets are CI-built, never uploaded from a maintainer workstation.
- The beta may be unsigned only when the asset and Release Notes say so explicitly; this workflow must reject a stable tag.
- The installer is current-user NSIS with no auto-start, service, task, file association, background updater, or administrator requirement.
- Runtime scanning, redaction, verification, and saving remain offline; no updater, analytics, crash upload, or HTTP client is added.
- Official assets are staged in a draft pre-release; a failed step must not leave a public partial Release.
- Third-party Actions use the full SHAs recorded below; permissions are read-only except in the release job.

```js
// scripts/release-contract.mjs
import { readFileSync } from "node:fs";
import { dirname, join, resolve } from "node:path";
import { fileURLToPath, pathToFileURL } from "node:url";

export function readReleaseIdentity(rootDir) {
  const packageVersion = JSON.parse(readFileSync(join(rootDir, "package.json"), "utf8")).version;
  const cargo = readFileSync(join(rootDir, "src-tauri", "Cargo.toml"), "utf8");
  const cargoVersion = cargo.match(/^version\s*=\s*"([^"]+)"/m)?.[1];
  const tauriVersion = JSON.parse(readFileSync(join(rootDir, "src-tauri", "tauri.conf.json"), "utf8")).version;
  return { packageVersion, cargoVersion, tauriVersion };
}

export function assertReleaseIdentity(rootDir, tag) {
  const identity = readReleaseIdentity(rootDir);
  const versions = Object.values(identity);
  if (versions.some((value) => value !== versions[0])) {
    throw new Error(`Version mismatch: ${JSON.stringify(identity)}`);
  }
  const version = versions[0];
  if (version !== "0.2.0-beta.1") throw new Error(`v0.2 workflow only permits 0.2.0-beta.1, got ${version}`);
  if (tag && tag !== `v${version}`) throw new Error(`Tag ${tag} does not match v${version}`);
  return version;
}

export function releaseAssetNames(version) {
  return {
    installer: `VeilSend_${version}_x64-setup-UNSIGNED.exe`,
    portable: `VeilSend_${version}_x64-portable-UNSIGNED.zip`,
    sbom: `veilsend-${version}-sbom.cdx.json`,
    checksums: "SHA256SUMS.txt",
  };
}

const modulePath = fileURLToPath(import.meta.url);
if (process.argv[1] && pathToFileURL(resolve(process.argv[1])).href === import.meta.url) {
  const root = resolve(dirname(modulePath), "..");
  process.stdout.write(`${assertReleaseIdentity(root, process.argv[2])}\n`);
}
```

- [ ] **Step 3: Implement strict asset staging**

```powershell
# scripts/stage-release.ps1
param(
  [Parameter(Mandatory=$true)][string]$Version,
  [Parameter(Mandatory=$true)][string]$ArtifactsDirectory
)
$ErrorActionPreference = 'Stop'
if ($Version -ne '0.2.0-beta.1') { throw "Unexpected release version: $Version" }
$workspace = (Resolve-Path (Join-Path $PSScriptRoot '..')).Path
$target = Join-Path $workspace 'src-tauri\target\release'
$artifacts = [System.IO.Path]::GetFullPath($ArtifactsDirectory)
New-Item -ItemType Directory -Force -Path $artifacts | Out-Null
$installers = @(Get-ChildItem -LiteralPath (Join-Path $target 'bundle\nsis') -Filter '*-setup.exe' -File)
if ($installers.Count -ne 1) { throw "Expected exactly one NSIS installer, found $($installers.Count)" }
$app = Join-Path $target 'veilsend.exe'
if (-not (Test-Path -LiteralPath $app -PathType Leaf)) { throw 'Missing release executable' }
$installerName = "VeilSend_${Version}_x64-setup-UNSIGNED.exe"
$portableName = "VeilSend_${Version}_x64-portable-UNSIGNED.zip"
Copy-Item -LiteralPath $installers[0].FullName -Destination (Join-Path $artifacts $installerName)
$temporaryBase = if ($env:RUNNER_TEMP) { [System.IO.Path]::GetFullPath($env:RUNNER_TEMP) } else { Join-Path $workspace 'tmp' }
$portableRoot = Join-Path $temporaryBase 'veilsend-portable-v0.2.0-beta.1'
if (Test-Path -LiteralPath $portableRoot) { Remove-Item -LiteralPath $portableRoot -Recurse -Force }
New-Item -ItemType Directory -Force -Path $portableRoot | Out-Null
Copy-Item -LiteralPath $app -Destination (Join-Path $portableRoot 'VeilSend.exe')
Copy-Item -LiteralPath (Join-Path $workspace 'LICENSE') -Destination $portableRoot
Copy-Item -LiteralPath (Join-Path $workspace 'RELEASE_NOTES.md') -Destination $portableRoot
Copy-Item -LiteralPath (Join-Path $workspace 'THIRD_PARTY_LICENSES.md') -Destination $portableRoot
Compress-Archive -Path (Join-Path $portableRoot '*') -DestinationPath (Join-Path $artifacts $portableName) -CompressionLevel Optimal
```

`RELEASE_NOTES.md` must start with `VeilSend 0.2.0-beta.1 is an unsigned pre-release` and explicitly say that SmartScreen may warn, users should verify SHA-256, and scanning/saving works offline after installation. Add the same disclosure to the README download section. `THIRD_PARTY_LICENSES.md` lists the license identifier and upstream project URL for every direct Cargo and production npm dependency, states that the CycloneDX SBOM is authoritative for the full transitive inventory, and reproduces the required MIT/Apache/BSD notice text used by direct dependencies.

- [ ] **Step 3: Add checksum verification and rerun protection**

Append `Remove-Item -LiteralPath $portableRoot -Recurse -Force` after the ZIP is closed; `$portableRoot` is the exact versioned child derived above, never the temporary root itself. In `release.yml`, insert this checksum verification before attestation:

```powershell
$lines = Get-Content -LiteralPath artifacts/SHA256SUMS.txt
foreach ($line in $lines) {
  if ($line -notmatch '^([0-9a-f]{64})  (.+)$') { throw "Malformed checksum line: $line" }
  $asset = Join-Path (Resolve-Path artifacts).Path $Matches[2]
  if (-not (Test-Path -LiteralPath $asset -PathType Leaf)) { throw "Missing checksummed asset: $($Matches[2])" }
  $actual = (Get-FileHash -Algorithm SHA256 -LiteralPath $asset).Hash.ToLowerInvariant()
  if ($actual -ne $Matches[1]) { throw "Checksum mismatch: $($Matches[2])" }
}
```

Fail if a Release for the tag already exists, allowing a workflow retry only after the maintainer inspects and explicitly deletes the still-draft failed Release.

```powershell
$existing = gh release view $env:GITHUB_REF_NAME --json isDraft 2>$null | ConvertFrom-Json
if ($existing) { throw "Release already exists; inspect and explicitly remove a failed draft before retrying." }
```

## Plan Self-Review

- Design sections 5–9 and 14 are covered: identity, CI, packaging, signing disclosure, draft publication, checksum, SBOM, provenance, WebView2, and offline boundary.
- Stable publication is impossible in this v0.2 workflow because the contract accepts only `0.2.0-beta.1`; signing is not simulated.
- Ordinary pull requests have `contents: read` and no secret-bearing step; only the tag job has release and attestation permissions.
- The package scripts never enumerate or delete outside the explicit runner-temp portable directory and caller-provided artifact directory.
- The draft Release remains unpublished until the acceptance plan is complete.
