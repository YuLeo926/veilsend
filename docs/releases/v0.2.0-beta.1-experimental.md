# 0.2.0-beta.1 experimental validation scope

Validation date: 2026-09-26. Binary source: `bbaa1c7488cff90338e73380161ffaa4875b9880`.

The maintainer explicitly approved experimental publication with limited local checks instead of requiring a clean Windows VM. This is **not** the strict clean-Windows acceptance record, and no all-pass acceptance JSON was created. Uninstallation was handed back to the maintainer and is not credited as a test pass.

## Observed checks

- Hosted release and quality workflows passed. The four original CI assets passed the production asset verifier, including SHA-256, unsigned executable state, archive layout, notice and declared SBOM-format checks, and GitHub provenance. Every asset was additionally bound to the immutable source commit above. SBOM-format validation is not a full inventory or schema audit.
- The actual current-user CI installer completed on a Windows 11 x64 development host without observed elevation. The installed program launched and displayed the expected beta version, build target, and commit. The launch context used a packaged-process virtualized application directory, further limiting compatibility conclusions.
- Synthetic text: five default findings were cleaned, rescan reported zero enabled-rule matches, and a separate cleaned text file was saved.
- Synthetic image: one face and three barcodes were covered in a separate PNG. Saved-file metadata, OCR, face, QR, and barcode checks completed with zero remaining supported risks.
- Synthetic three-page PDF: three text findings on page 1 and five visual findings on page 2 were covered, plus one manually drawn cover on page 3. Saved bytes, page count and sizes, rerendered pages, and text/face/QR/barcode checks passed with zero remaining findings. Seven predefined source-content markers were absent from the saved bytes; this is not a separate exhaustive PDF-object audit.
- Source fixture hashes were unchanged after these workflows. Default receipt UI excluded output SHA-256. No real user content was used.

## Not verified

- Clean Windows 10/11 compatibility, installation without pre-existing developer dependencies, or WebView2 bootstrap on a runtime-free system.
- Portable startup and workflows (archive/executable checks passed, but the portable app was not run).
- Installed Start Menu launch, uninstall preservation, and final app-exit residue checks.
- Operation with the network disconnected.
- The full drag/drop rejection matrix, screenshot paste, copied diagnostics/receipt privacy matrix, and complete PDF zoom/keyboard/coordinate-invariance matrix. Basic page navigation, a manual cover, and Fit page were exercised only.

This build remains unsigned and experimental, not stable or generally certified safe. `Verified` describes supported checks on a particular output, not a guarantee that it is safe to share. Preserve originals and manually inspect outputs. The original assets and tag are unchanged; release-page validation notes supersede the older validation scope in the ZIP's bundled notice.
