CLEAR BOUNDARIES

Local processing.
Human judgment.

No account in the desktop app. No analytics or crash uploads. No automatic sharing.

What stays on my computer?

The desktop app processes source content locally. It does not upload files or use cloud inference. The installer may need internet access to obtain Microsoft WebView2. Disconnected operation has not yet been verified for this beta.

What does “Verified” actually mean?

Supported checks completed for that output with no remaining supported findings or intentional exceptions. Detectors can miss information. Keep originals and manually inspect every output; this is not a safety guarantee or a compliance certification.

What can this beta handle?

UTF-8 text up to 10 MiB; JPEG/PNG up to 25 MiB; unencrypted PDFs up to 50 MiB and 50 pages, subject to render limits. One file at a time. No Office files, batch processing or Mac/Linux desktop builds.

Is it ready for critical work?

No. This is an unsigned experimental beta, not a stable release. Core workflows were smoke-tested on one Windows 11 development computer with synthetic data. A portable text trial also passed on that development computer. Clean-system compatibility, portable image/PDF workflows and uninstall preservation remain unverified. Start with fake data.
